

**ArtiQuity** is a full-stack online learning platform built specifically for artists and creative professionals. It empowers users to learn, teach, and monetize their skills through interactive and certified courses.

##  Key Features
- **User Roles**: Support for Students, Instructors, and Admins
- **Course Management**: Multimedia course creation with videos, docs.
- **Secure Payments**: Integrated Stripe and PayPal for enrollment transactions
- **Progress Tracking**: Users can monitor their learning journey visually

##  Tech Stack
- **Frontend**: HTML, CSS, JavaScript 
- **Backend**: Python 
- **Framework**: Django
- **Database**: SQL
- **Payment APIs**: Stripe
- **Tools**: Git, GitHub, Agile Workflow
